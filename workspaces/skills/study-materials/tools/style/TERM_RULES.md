Within ONE item (one JSON object: its t, q, b[], tbl cells, cap), the **first** occurrence of a term is written `English（中文）`; later occurrences in the same item should be English only (keeps the sheet compact). Section-header objects ({"sec": ...}) and titles also follow the rule (title `t` counts as the first occurrence, so the title should be like `Bias Removal & Shrinkage（去偏置与收缩）`).
3. Normalize existing forms: `中文（English）`, `中文(English)`, `中文 English`, `English 中文` → `English（中文）`. 6. Do NOT change meaning, numbers, formulas, page references (e.g. 〔W10 p9〕 / "W11 p14"), the order of bullets, the number of bullets, table shapes, or JSON keys. Keep `**bold**` markers balanced; if a bolded Chinese term is converted, bold the whole `**English（中文）**`.
