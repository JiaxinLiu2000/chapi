# 技能：定时任务（schedule_task）

## 何时使用
- 需要"X 秒/分钟后再做某事"、稍后复查、等待一段时间后再继续。

## 如何使用
- 调用 `mcp__chapi__schedule_task({ delaySeconds, description })`。
- 左侧监控会出现一个 **"定时检查"** 代理并**实时倒计时**（⏳ 还有 Xs），到点自动在本会话执行 `description`，用户全程可见。
- **不要用 Bash `sleep` 阻塞等待**（既看不到倒计时、也占住运行）。一律用本工具。
- `delaySeconds` 范围 5 ~ 86400（24h）；`description` 写清楚到点要做什么、产物去向。

## 注意
- 到点会以一条新消息触发执行，随后按正常流程推进（先 `set_plan`、必要时并行子代理等）。
- 若任务被删除/会话关闭，未触发的定时任务会失效。
